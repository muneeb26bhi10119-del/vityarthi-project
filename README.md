# Tic Tac Toe game
This is a simple two player game that I made using python
# About this project 
The game is played between two players, X and O . Each player gets a turn to choose a position from 1 to 9
After every turn, the program checks the rows, columns and diagonals to see if a player has won. If all the position are filled without a winner, The game ends in a draw
