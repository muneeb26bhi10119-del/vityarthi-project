# Tic Tac Toe Game

This is a simple two-player Tic Tac Toe game that I made using Python.

## About the Project

I made this project to practice the basic concepts of Python by creating a small game. The game is played between two players, X and O. Each player takes turns choosing a position from 1 to 9.

After every turn, the program checks the rows, columns, and diagonals to see if a player has won. If all the positions are filled without a winner, the game ends in a draw.

## Python Concepts Used

- Lists
- Functions
- For loop
- If-else statements
- User input
- Basic conditions

## How to Play

1. Run the Python program.
2. Choose a position from 1 to 9.
3. Player X takes the first turn.
4. Player O takes the next turn.
5. Continue until a player wins or the game ends in a draw.

## Purpose

The main purpose of this project was to improve my understanding of Python and learn how different basic concepts can be combined to create a working program.
